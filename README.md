# ინფორმატიკა და კომპიუტერული სისტემები — ინტერაქციული ტესტი

სამაგისტრო გამოცდის სატესტო ტრენაჟორი სპეციალობაში. სულ **234 კითხვა** ექვს სექციად, ყველა პასუხის ვარიანტითა და სწორი პასუხის განმარტებით.

## სექციები

| სექცია | კითხვები |
|---|---|
| კომპიუტერის არქიტექტურის და ორგანიზაციის საფუძვლები | 56 |
| დაპროგრამება | 50 |
| მონაცემთა სტრუქტურები და ალგორითმები | 5 |
| კომპიუტერული ქსელები | 18 |
| SQL Server (მონაცემთა ბაზები) | 91 |
| ოპერაციული სისტემები | 14 |

## შესაძლებლობები

- **სწავლის რეჟიმი** — პასუხის არჩევისთანავე ჩანს შედეგი და განმარტება
- **გამოცდის რეჟიმი** — შემოწმება ბოლოს, ნამდვილი ტესტივით
- სექციების არჩევა, კითხვებისა და პასუხების არევა, კითხვების რაოდენობის შეზღუდვა
- შედეგების გვერდი სექციების მიხედვით სტატისტიკით და შეცდომების გარჩევით
- დათვალიერების რეჟიმი ძებნით — ყველა კითხვა სწორი პასუხებით
- პროგრესი ინახება ბრაუზერში (localStorage)
- კლავიატურა: `1`–`4` პასუხის ასარჩევად, ისრები ნავიგაციისთვის

## გაშვება

დამოკიდებულებები არ სჭირდება — უბრალოდ გახსენი `index.html` ბრაუზერში.

## სტრუქტურა

```
index.html          — გვერდის მარკაპი
style.css           — სტილები
app.js              — ქვიზის ძრავა
data/*.js           — კითხვები სექციების მიხედვით
```

კითხვების დასამატებლად ან შესასწორებლად ჩაასწორე შესაბამისი ფაილი `data/` საქაღალდეში.
